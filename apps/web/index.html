Commit Wars

Paste a GitHub link. The app reads the repository's history and turns it into a stick-figure fight: every hero is someone who wrote the commits, and every enemy is a bug or issue they actually fixed.

GitHub token not set

Without a token the app can make 60 requests an hour, which covers about 2,000 commits with no file counts or linked issues. With one, every enemy gets its pull request, its closed issue and its real size.

Create a fine-grained token with read-only access to public repositories (or to the private ones you want to replay). It stays in this browser and is only sent to api.github.com.
